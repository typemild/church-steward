# 요구사항 명세서

청지기가 어떻게 동작해야 하는지를 정한 기준 문서입니다. 기능을 바꿀 때는 이 문서도 함께 고칩니다.
구현 구조는 [아키텍처](architecture.md)에 있습니다.

## 범위
* 수입과 지출을 예산별로 기록하는 **단식부기** 방식임.
* **복식부기는 제공하지 않으며 제공할 계획도 없음.** 차변/대변 분개, 계정과목 체계, 재무상태표 등은 범위 밖임.

## 1. 대시보드 (Dashboard)
* **탭 1: 최근 현황**
  - 최근 발생한 수입/지출의 총액 및 요약 정보 표시.
  - 최근 발생한 수입/지출 내역 리스트(최신순) 출력.
* **탭 2: 예산 대비 집행 현황**
  - 설정된 예산 항목별로 '예산 금액' 대비 '실제 집행 금액'을 시각적으로 비교 표시.

## 2. 설정 (Settings)
* **회계 연도 관리**
  - 회계 연도의 추가, 수정(이름과 기간), 삭제, 마감, 마감 취소 기능. 추가할 때 기존 회계 연도의 예산을 복사할 수 있음.
  - **이름과 기간으로 정의**: 회계 연도는 달력의 해가 아니라 이름과 기간으로 정의하므로 한 해에 둘 이상 둘 수 있음. (예: "2026년", "2025년 상반기", "2024년 1차")
  - **이름**: 필수이며 30자 이내. 다른 회계 연도와 같을 수 없음.
  - **기간**: 회계 연도마다 시작일과 종료일을 지정함. 달력의 해와 어긋나도 되고(예: "2026년" = 2025년 12월 1일 ~ 2026년 11월 30일), 길이가 12개월이 아니어도 됨.
  - **기간 제약**: 다른 회계 연도와 하루도 겹칠 수 없음. 회계 연도 사이에 빈 기간이 있는 것은 허용함.
  - **기간 수정**: 이미 등록된 수입/지출이 기간 밖에 놓이지 않도록, 시작일은 가장 이른 내역의 날짜 이전으로, 종료일은 가장 늦은 내역의 날짜 이후로만 지정할 수 있음.
  - **순서**: 목록은 시작일이 늦은 것부터 나열함. "직전 회계 연도"는 시작일이 더 앞선 회계 연도 중 가장 최근 것을 뜻함.
  - **마감**: 마감하면 그 시점의 총 수입, 총 지출, 차액을 계산해 저장하고 회계 연도 목록에 표시함. 마감된 회계 연도는 이름·기간 수정과 삭제를 할 수 없고, 그 회계 연도의 예산(추가/수정/삭제/순서 변경)과 수입/지출(추가/수정/삭제)도 바꿀 수 없으며 조회만 가능함. 다만 마감된 회계 연도의 예산을 새 회계 연도로 복사하는 것은 가능함.
  - **마감 취소**: 저장했던 총 수입, 총 지출, 차액을 지우고 다시 수정할 수 있는 상태로 되돌림. 마감과 마감 취소는 모든 사용자가 할 수 있으며 활동 기록에 "마감", "마감 취소"로 기록됨.
* **봉헌자/수취인 관리 (Donor/Recipient Management)**
  - **데이터 구조**: 구분(개인/내부부서/업체/단체/기타), 성명(100자 이내), 비고(100자 이내). 업체는 물품이나 서비스를 사고파는 곳(가게, 은행, 공과금 회사 등), 단체는 그 밖의 기관과 모임(선교회, 다른 교회, 복지시설, 관공서 등), 기타는 어디에도 맞지 않는 대상임.
  - **구분 수정**: 등록한 뒤에도 구분, 성명, 비고를 수정할 수 있음. 내역에는 성명만 기록 당시의 값으로 남으므로, 구분을 바꿔도 과거 내역은 변하지 않음.
  - **기능**: 봉헌자와 수취인을 통합 관리. 단, **수취인은 '그룹' 기능을 사용하지 않음**.
  - **삭제 로직**: 해당 대상과 연결된 수입/지출 내역이 존재하는 경우 삭제 불가.
  - **상태 관리**: '숨김' 기능 지원 (수입 입력 시 자동완성 목록에서 제외).
* **프로그램 설정**
  - 설정 메뉴의 "관계자(봉헌자/수취인) 관리"와 "비밀번호 변경" 사이의 탭. 값을 고르면 바로 저장하고(예산별 보기 칸은 다이얼로그에서 저장), 저장이 끝나면 선택란이나 버튼 오른쪽에 체크 아이콘을 잠시 표시함.
  - 사용자별 설정이 아니라 프로그램 전체에 하나뿐이며, 관리자뿐 아니라 모든 사용자가 바꿀 수 있음. DB에 저장되어 백업에 함께 들어감. 활동 기록은 남기지 않음.
  - **주간 결산 요일**: 주간은 결산 요일 다음 날부터 결산 요일까지임. 최초 실행 화면에서 고르며 기본값은 일요일(주간은 월요일 ~ 일요일)임. 설정한 적이 없는 기존 데이터와 과거 버전의 백업을 복원한 경우에도 일요일임. 수입/지출 관리의 "주간"과 주간 회계 결산 보고서에 함께 적용함. 결산 요일을 바꾼 뒤 그 화면에 들어오면 보고 있던 주간을 새 기준으로 다시 잡음.
  - **예산별 보기 칸**: 수입/지출 관리 "예산별 보기"의 수입 표와 지출 표에서 칸의 순서와 숨길 칸을 정함. "칸 설정" 버튼으로 다이얼로그(수입 내역/지출 내역 탭)를 열어 정하고 저장함. 칸의 구성과 규칙, 기본 순서는 주간 회계 결산 보고서의 주간 내역과 같지만(4절) 보고서 양식과 따로 저장하므로, 한쪽을 바꿔도 다른 쪽은 바뀌지 않음. 설정한 적이 없거나 저장된 설정이 지금 버전의 칸 구성과 맞지 않으면 기본 순서임.
* **사용자 계정 관리 (User Management) - [관리자 전용]**
  - **최초 실행 보안 로직**: 
    1. 프로그램 최초 실행 시, DB 접근을 위한 **랜덤 암호화 키(Master Key)**를 생성함.
    2. 초기 관리자 계정을 생성하며, 위에서 생성된 랜덤 키를 관리자의 비밀번호로 양방향 암호화하여 설정 파일에 저장함.
  - **최초 실행 화면**: 창 제목은 "청지기 초기 설정"임. 먼저 "시작 방법 선택"에서 "새로 시작"과 "백업에서 복원" 중 하나를 고름. 이 화면은 프로그램 아이콘과 환영 문구("청지기에 오신 것을 환영합니다") 아래에 두 선택지를 둠. 두 선택지는 아이콘, 제목, 설명, 오른쪽 꺾쇠를 담은 카드 모양 버튼임. 처음에는 아무것도 선택되지 않은 상태이고, 마우스를 올리거나 ↑/↓ 키로 선택하며(선택된 뒤로는 하나만 선택된 상태를 유지), 누르거나 Enter·Space로 고름. 창 높이는 이 화면과 복원 화면은 각자의 내용에 맞추고, 세 단계는 셋 중 가장 큰 단계에 맞춘 같은 높이를 씀. "백업에서 복원"은 새 창을 띄우지 않고 같은 창에서 복원 화면(백업 파일, 관리자 비밀번호, 주의사항, "이전"/"복원" 버튼)으로 바뀌며, "이전"으로 선택 화면에 돌아옴. "새로 시작"을 고르면 관리자 계정, 주간 결산 요일, 회계 연도의 세 단계로 입력받음. 시작 방법 선택은 단계에 넣지 않으며 그 화면에서는 단계 표시를 숨김. 세 단계의 화면 맨 위의 단계 표시는 화살표 모양의 칸 세 개를 이어 붙이고 칸마다 동그라미 번호와 단계 이름을 적으며, 지금 단계는 강조 색 칸에 흰 글자, 지난 단계는 연한 강조 색 칸, 남은 단계는 흰 칸에 회색 글자로 표시함. 그 아래를 가로선으로 나누고 단계의 제목, 할 일을 알리는 안내 글, 입력란을 담은 카드를 차례로 둠.
    - 1·2단계는 "다음", 3단계는 "완료" 버튼이고, 모든 단계에 "이전" 버튼을 둠(1단계의 "이전"은 시작 방법 선택으로 돌아감). 이전 단계로 돌아가도 입력한 값은 유지함.
    - 각 단계의 입력값은 다음 단계로 넘어가기 전에 검증함(1단계: 비밀번호 규칙과 일치, 3단계: 회계 연도 추가와 같이 이름 필수·30자 이내, 종료일은 시작일 이후).
    - 초기화(DB 파일 생성, 관리자 생성, 주간 결산 요일 저장, 회계 연도 생성)는 3단계에서 "완료"를 누를 때 한 번에 실행함. DB 파일을 만든 뒤에 실패하면 되돌릴 수 없기 때문임. 그 전에 창을 닫으면 아무것도 만들지 않고 프로그램을 끝내며, 다음 실행 때 다시 최초 실행 화면이 나옴. 초기화하는 동안은 창을 닫을 수 없음.
    - 2단계의 주간 결산 요일은 기본값이 일요일이며, 고른 값은 기본값이어도 늘 프로그램 설정에 저장함. 3단계의 회계 연도는 기본값이 이름 "{올해}년", 기간 올해 1월 1일 ~ 12월 31일임. 두 값 모두 나중에 설정에서 바꿀 수 있다고 안내함.
    - 키보드만으로 입력을 마칠 수 있음. Enter를 누르면 다음 입력란으로 옮기고, 단계의 마지막 입력란이면 "다음"(3단계는 "완료")을 누른 것과 같음.
  - **사용자별 보안 메커니즘**: 
    - 모든 사용자는 각자의 비밀번호로 암호화된 '랜덤 DB 접근 키' 값을 설정 파일에 개별 보유함.
    - 로그인 시, 입력한 비밀번호로 설정 파일 내의 암호화된 키를 복호화하여 DB에 접근함.
  - **계정 권한 및 제약**:
    - **관리자(Admin)**: ID는 **"관리자"**로 고정되며 모든 기능 사용 가능. 단, 사용자 관리 메뉴에서 본인(관리자)은 조회/추가/수정/삭제가 불가능함.
    - **사용자(User)**: 사용자 관리를 제외한 모든 기능 사용 가능.
  - **계정 수정 및 유지보수**:
    - **데이터 구조**: 성명(ID, 100자 이내), 비밀번호, 비고(100자 이내).
    - **수정 범위 제한**: 사용자의 정보 중 **"비밀번호"와 "비고"만 수정 가능하며, 성명(ID)은 수정할 수 없음**.
    - **삭제 시 영향**: 사용자를 삭제하더라도, 해당 사용자가 과거에 작성한 수입/지출 내역의 '입력자 성명'은 변경되지 않고 그대로 유지됨.
    - **비밀번호 변경(공통)**: 비밀번호 변경 시 설정 파일 내 저장된 DB 접근 키 값도 신규 비밀번호로 재암호화되어 즉시 갱신됨.
    - **본인 비밀번호 변경**: 새 비밀번호가 현재 비밀번호와 같으면 변경하지 않음. 관리자가 사용자 관리에서 다른 사용자의 비밀번호를 바꿀 때는 이 검사를 하지 않음(오류 문구로 그 사용자의 현재 비밀번호를 알아낼 수 있기 때문).

## 2-1. 예산 관리 (Budget Management)
* 설정이 아닌 주 메뉴이며(보고서 바로 아래), 대시보드, 수입/지출 관리, 보고서와 같이 주 메뉴 상단에서 선택한 회계 연도의 예산을 다룸.
* **예산 계획 수립**: 회계 연도별로 수입 예산과 지출 예산을 계층으로 구성하고 항목별 금액을 관리함. 수입 예산과 지출 예산을 좌우로 나란히 표시함.
* **예산명**: 50자 이내이며 `<`, `>`를 쓸 수 없음. (전체 예산명 "예산A > 예산B"의 구분 문자와 섞이지 않게 하기 위함)
* **비고**: 예산에 설명을 남기는 선택 입력이며 100자 이내(넘는 글자는 입력란이 막음). 추가/수정 다이얼로그와 상세 보기에 한 줄 입력란으로 두고, 예산 목록과 예산 선택 다이얼로그에는 표시하지 않음. 비고를 바꾸면 활동 기록에 남김. 비고가 없던 기존 예산과 과거 버전의 백업은 비고가 비어 있음. 회계 연도를 추가하면서 예산을 복사하면 비고도 함께 복사함.
* **진행 현황**: 예산마다 실제 금액(수입 예산은 수입액, 지출 예산은 집행액)과 예산 대비 비율(달성률/집행률)을 함께 표시함. 상위 예산은 하위 예산의 내역까지 합산함.
* **마감된 회계 연도**: 예산을 조회만 할 수 있음. "마감된 회계 연도입니다. 조회만 할 수 있습니다."라는 안내를 표시하고, 추가/수정/삭제/순서 변경 버튼 대신 상세 보기 버튼을 둠. 상세 보기 버튼이나 예산 더블클릭으로 "예산 상세 보기" 다이얼로그(수정 다이얼로그와 같은 내용을 바꿀 수 없게 표시하며, 맨 위에 같은 안내가 있고 닫기 버튼만 있음)를 열 수 있음.

## 3. 수입/지출 관리 (Income/Expense Management)
* **데이터 기록의 불변성**: 모든 수입/지출 내역에는 **해당 내역의 입력자(사용자) 성명이 반드시 저장**되며, 사용자가 삭제되거나 변경되어도 기록된 시점의 이름은 영구히 유지됨.
* **지출 항목 확장**: 지출 내역에 **'수취인'** 필드 추가 (봉헌자/수취인 관리 메뉴 참조, 그룹 기능 미사용).
* **봉헌자/수취인 필수 입력**: 수입은 봉헌자를 1명 이상, 지출은 수취인을 1명 입력해야 저장할 수 있음. 봉헌자가 없는 수입(무명 헌금, 은행 이자 등)은 "무명", "OO은행" 같은 대상을 등록하여 입력함.
* **내용과 비고**: 각각 100자 이내임. 지출은 무엇에 쓴 돈인지 알 수 있도록 내용을 반드시 입력해야 하고, 수입의 내용과 비고는 비워 둘 수 있음. 이전 버전에서 내용 없이 입력한 지출은 업데이트할 때(과거 버전의 백업은 복원할 때) 그 내역의 예산명(전체 경로가 아니라 최하위 예산명 하나)으로 채움.
* **날짜 제한**: 수입/지출의 날짜는 그 내역이 속한 회계 연도의 기간(시작일과 종료일 포함) 안에 있어야 함.
* **입력 날짜의 초기값**: 추가 다이얼로그의 날짜는 오늘이며, 오늘이 선택한 회계 연도의 기간 밖이면 기간에서 오늘과 가장 가까운 날(종료일 또는 시작일)로 정함. 이렇게 오늘이 아닌 날로 정했으면 날짜 입력란 아래에 경고 색의 글자로 회계 연도를 확인하라고 안내함(예: "오늘(2027-01-05)이 2026년 회계 연도의 기간(2026-01-01 ~ 2026-12-31) 밖이라 종료일로 정했습니다. 회계 연도를 확인해주세요."). 날짜를 바꾸면 안내는 사라짐. 마지막으로 입력한 날짜를 이어 쓰는 경우(같은 회계 연도에서 두 번째 추가부터)와 수정 다이얼로그에는 보이지 않음. 지난 회계 연도에 일부러 입력하는 경우도 있으므로 안내만 하고 저장을 막지 않음.
* **준비 안내**: 수입/지출을 입력할 수 없는 상태이면 팝업으로 알리고 해당 메뉴로 바로 이동하게 함.
  - 안내하는 상황
    1. 오늘이 속한 회계 연도가 없음(오늘 날짜가 어느 회계 연도의 기간에도 들지 않음. 회계 연도 사이의 빈 기간 포함): 오늘 날짜로 수입/지출을 입력하려면 새 회계 연도를 추가해야 한다고 알림. 바로가기는 "회계 연도 관리로 이동"(설정 > 회계 연도 관리).
    2. 회계 연도에 수입 예산과 지출 예산 중 하나라도 등록된 것이 없음: 예산을 등록해야 그 구분의 수입/지출을 입력할 수 있다고 알리며 없는 구분을 적음. 바로가기는 "예산 관리로 이동"(주 메뉴 상단의 회계 연도를 안내한 회계 연도로 바꾼 뒤 이동). 마감된 회계 연도는 대상에서 뺌.
  - 안내하는 때: 수입/지출 관리 메뉴에 들어올 때(1을 확인하고, 1이 아니면 주 메뉴 상단에서 선택한 회계 연도로 2를 확인함. 수입/지출 관리에서 회계 연도를 바꿀 때도 같음). 로그인 직후의 첫 화면(대시보드)에서는 안내하지 않음. 두 상황에 모두 해당하면 회계 연도를 먼저 만들어야 하므로 1만 안내함.
  - 같은 안내는 프로그램을 다시 시작하기 전까지 한 번만 보여줌(1은 한 번, 2는 회계 연도마다 한 번). 보여준 기록은 저장하지 않음.
  - 팝업에는 안내 문구, 바로가기 버튼, "닫기" 버튼을 둠. 바로가기를 누르면 팝업을 닫고 그 메뉴로 이동함. 두 메뉴 모두 모든 사용자가 쓸 수 있으므로 권한에 따라 막지 않음.
* **일괄 변경과 일괄 삭제**: "예산별 보기"와 "건별 보기" 두 탭 모두에서 선택한 여러 건의 예산이나 봉헌자/수취인을 한 번에 바꾸거나 한 번에 삭제할 수 있음.
  - 툴바에 예산 일괄 변경, 관계자 일괄 변경 버튼을 따로 둠. 선택된 내역이 없으면(예산별 보기에서 예산 행만 선택한 경우 포함) 꺼지며, 건별 보기에서 수입과 지출이 함께 선택되어도 꺼짐(툴팁으로 이유를 안내함). 예산별 보기에서 예산 행은 대상에서 빠짐.
  - **예산 일괄 변경**: 해당 구분의 말단 예산 하나를 고름. 선택한 내역의 예산이 모두 같으면 그 예산이 선택된 상태로, 다르면 비어 있는 상태로 다이얼로그가 열림.
  - **관계자 일괄 변경**: 선택한 내역의 봉헌자/수취인을 모두 고른 대상으로 바꿈(수입은 1명 이상이며 그룹 기능 사용, 지출은 1명). 선택한 내역의 봉헌자/수취인이 순서까지 모두 같으면 그 대상이 현재 성명의 칩으로 들어 있는 상태로, 다르면 비어 있는 상태로 다이얼로그가 열림. 바뀐 내역의 성명은 모두 현재 성명으로 기록됨(대상이 바뀌지 않은 내역 포함). 봉헌자가 2명 이상이면 입력할 때와 같이 그룹을 자동으로 만듦.
  - 값이 이미 같은 내역도 건너뛰지 않고 똑같이 처리하며, 활동 기록은 내역마다 "수정"(삭제는 "삭제")으로 남김.
  - 하나의 작업으로 처리하므로 한 건이라도 바꾸거나 삭제할 수 없으면(마감된 회계 연도의 내역, 다른 곳에서 이미 삭제한 내역 등) 아무것도 바뀌지 않음. 성공하면 목록을 다시 조회하고 선택을 해제함.
* **예산별 보기의 칸**: 수입 표와 지출 표는 예산 행 아래에 내역을 한 줄에 한 건씩 보여줌. 첫 번째 칸에는 예산 행이면 전체 예산명을, 내역 행이면 "[4/7] 홍길동"처럼 일자와 첫 번째로 정한 칸(봉헌자/수취인 또는 내용)의 값을 적음(칸 제목은 "일자 · 봉헌자" 등). 나머지 칸은 정한 순서대로 두고 숨긴 칸은 표에서 뺌(보고서와 달리 아랫줄에 따로 적지 않음). 정렬은 보고서와 같이 금액은 오른쪽, 첫 번째 칸이 아닌 봉헌자/수취인은 가운데, 나머지는 왼쪽임. 기본 순서는 수입이 (일자) 봉헌자, 금액, 내용, 비고이고 지출이 (일자) 내용, 금액, 수취인, 비고임. 칸은 프로그램 설정의 "예산별 보기 칸"에서 정하며, 두 표의 제목 옆 톱니바퀴 버튼(툴팁 "칸 설정")을 누르면 설정 위치를 안내하고 확인하면 설정 > 프로그램 설정으로 이동함. 이 버튼은 보기만 바꾸므로 마감된 회계 연도에서도 쓸 수 있음.
* **마감된 회계 연도**: 수입/지출을 추가, 수정, 삭제할 수 없고 조회만 가능함. 예산 관리와 같은 안내를 표시하고, 두 탭의 일괄 변경/추가/수정/삭제 버튼 대신 상세 보기 버튼을 둠. 상세 보기 버튼이나 내역 더블클릭으로 "수입 상세 보기"/"지출 상세 보기" 다이얼로그(수정 다이얼로그와 같은 내용을 바꿀 수 없게 표시하며, 맨 위에 같은 안내가 있고 닫기 버튼만 있음)를 열 수 있음.
* **목록 조회 및 검색**
  - 조회 조건: 기간, 구분(수입/지출), 봉헌자/수취인 성명(복수 지정 가능), 예산 항목별 필터링.
  - 조회 기간: 단위(1일/주간/월간/분기/연간/기타)를 고르고 화살표로 이동함. "주간"은 프로그램 설정의 주간 결산 요일 다음 날부터 결산 요일까지임. 시작일이나 종료일을 직접 지정하면 단위가 "기타"로 바뀌며, "기타"에서는 화살표가 지정한 기간의 날 수만큼 이동함(예: 10월 1일 ~ 10월 10일이면 다음 기간은 10월 11일 ~ 10월 20일). 다음 기간 화살표 오른쪽의 "오늘" 버튼은 지금 고른 단위에서 오늘이 속한 기간으로 옮기고 바로 조회함. 오늘이 속한 기간이 회계 연도의 기간과 하루도 겹치지 않거나, 이미 그 기간을 보고 있거나, 단위가 "연간"(회계 연도 기간 전체)이면 버튼은 비활성화됨.
  - 봉헌자/수취인은 자동완성으로 고르며, 검색·정렬·표시 개수는 아래 입력의 자동완성과 같음. "신규 추가" 항목은 없고, 나머지 결과 안내는 목록 맨 아래에 표시함.
  - 수입/지출 내역의 총합을 실시간으로 계산하여 표시.
* **수입/지출 입력 및 계층형 자동완성 (Hierarchical Autocomplete)**
  - **기본 구조**: 관계자 최대 5명과 "신규 추가" 항목을 표시. 목록이 길어 아래쪽 입력란을 가리지 않도록 적게 둠.
  - **검색**: 성명이나 비고에 입력한 글자가 들어 있는 대상을 찾음. 숨긴 대상과 이미 입력한 대상은 제외함.
  - **정렬**: 성명 일치 → 성명이 입력한 글자로 시작 → 성명에 입력한 글자 포함 → 비고에 입력한 글자 포함 순이며, 같은 순위 안에서는 가나다순.
  - **나머지 결과 안내**: 결과가 5명을 넘으면 "신규 추가" 아래에 "검색 결과가 N건 더 있습니다..."를 작은 글씨로 오른쪽 정렬해 표시함. 마우스를 올리면 손 모양 커서와 밑줄로 누를 수 있음을 알리며, 누르면 결과를 모두 보여주며, 8개 항목을 넘으면 스크롤함. 키보드로는 선택할 수 없음.
  - **레이아웃**: `[구분] 성명` / `비고`(작은 글씨, 말줄임표 및 Tooltip 적용). 비고가 없으면 비고 줄을 빼고 한 줄로 표시함. 항목 좌측에 연필(수정)/휴지통(삭제) 아이콘 배치.
  - **계층형 서브 목록 (Group Detail)**: 
    - 소속 그룹이 있는 항목 포커스 시 해당 항목 우측에 서브 목록 오픈 (`→`/`←` 키로 이동).
    - 소속 그룹이 있는 항목은 오른쪽 끝에 세모(▶) 아이콘을 표시해 서브 목록이 있음을 알림.
    - 구성: 해당 봉헌자가 속한 그룹들. 최대 5개까지 표시하고 그 이상은 스크롤로 조회.
    - 그룹 상세: 구성원을 칩으로 나열하고(많으면 여러 줄), 칩의 Tooltip으로 각 멤버의 정보(`[구분] 성명` / `비고`)를 표시. 그룹 항목에는 휴지통 아이콘 제공.
    - 서브 목록 최상단에 "한 번에 추가" 안내 문구 표시.
  - **수입 입력 특화**: 수입 입력 시에만 '그룹' 기능이 활성화됨.
  - **신규 추가 프로세스**: "신규 추가" 선택 $\rightarrow$ 팝업 창에서 정보 입력 $\rightarrow$ 저장 즉시 수입 입력 화면으로 복귀하며 해당 봉헌자가 입력란에 자동 반영됨.

## 4. 보고서 (Reporting)
* **공통**
  - 모든 보고서는 A4 세로 용지 기준이며, 소규모 교회의 보고서가 가급적 한 장에 담기도록 글자와 여백을 작게 잡음.
  - 흑백 인쇄를 전제로 색을 쓰지 않고 회색조와 채움/비움으로만 구분함.
  - 기능: 조회(미리보기), PDF 저장, 인쇄. 미리보기·PDF·인쇄물의 줄바꿈과 페이지 나눔은 항상 같음.
  - 집계는 회계 연도에 속한 내역 전체를 대상으로 함. (내역의 날짜는 입력할 때 회계 연도의 기간 안으로 제한됨)
  - 보고서 종류: 주간 회계 결산 보고서, 회계 연도 예산안, 회계 연도 결산 보고서, 회계 연도 결산 세부 내역서. 회계 연도 예산안은 수입 예산안과 지출 예산안을, 회계 연도 결산 세부 내역서는 수입 결산 세부 내역서와 지출 결산 세부 내역서를 이 순서로 묶은 하나의 보고서임(구성이 같은 수입과 지출만 묶음. 서식이 하나이므로 구성이 다른 결산 보고서는 묶지 않음). 묶인 보고서는 각각 새 페이지에서 시작하고 제목도 각자 붙이며, 페이지 번호는 문서 전체로 셈. 서식, 양식, 미리보기 설정, 인쇄와 PDF 저장은 묶은 보고서 단위임.
* **서식 조정** (보고서마다 사용자별로 저장)
  - 글꼴: 프로그램에 포함한 나눔고딕(기본)과 나눔명조 중에서 고름.
  - 글자 크기: +/- 버튼을 누를 때마다 모든 글자를 0.5pt씩 키우거나 줄임. 보고서에서 가장 작은 글자가 6pt ~ 12pt를 벗어나지 않는 범위에서만 조정됨. (페이지 번호는 조정하지 않음)
  - 행 간격: 표의 행과 내역 줄의 높이를 글자 높이의 100% ~ 200%로 +/- 버튼을 누를 때마다 10%씩 조정함. 기본은 130%.
  - 초기화: 그 보고서의 글꼴, 글자 크기, 행 간격, 한 페이지에 맞춤(꺼짐)을 기본값으로 되돌리고 바로 저장함.

  - 예산별 금액, 점유율, 실제 금액(수입액/집행액), 비율(달성률/집행률), 비고(예산의 비고)와 총계.
  - 칸 순서를 바꿀 수 있으나(양식) "예산 항목"은 항상 첫 번째 칸임. 기본 순서는 예산 항목, 예산액, 점유율, 수입액(집행액), 달성률(집행률), 비고.
  - 제목 아래의 회계 연도 이름과 기간, PDF 파일 이름("2026년 회계 연도 결산 세부 내역서"), 칸 폭, 비고를 다시 적는 방식은 예산안과 같음.

## 5. 데이터 관리 (Data Management) - [관리자 전용]
* **구성**: "백업/복원", "관계자", "예산", "수입/지출" 네 탭. 관계자, 예산, 수입/지출의 가져오기/내보내기는 다른 프로그램의 데이터를 옮겨 오거나 수기로 관리하던 데이터를 한꺼번에 반영하기 위한 기능임. 수입/지출을 가져오려면 관계자와 예산이 먼저 있어야 하므로 그 순서로 탭을 둠.
* **회계 연도 선택**: 예산 탭과 수입/지출 탭은 주 메뉴 상단의 회계 연도를 쓰지 않고 탭마다 회계 연도 선택란을 따로 둠. 초기값만 주 메뉴 상단의 선택을 따름. 마감된 회계 연도는 내보내기만 할 수 있음. 관계자는 회계 연도에 속하지 않으므로 관계자 탭에는 회계 연도 선택란이 없음.
* **전체 데이터 백업/복원**
  - **백업**: 데이터베이스 전체를 H2의 SQL 덤프(`SCRIPT`)로 내보내고, 설정 파일의 사용자별 DB 접근 키, 백업 정보(프로그램 버전, 일시)와 함께 파일 하나로 묶음.
  - **암호**: 별도의 백업 암호를 두지 않음. 덤프는 기존 DB 접근 키로 암호화하므로, 복원한 뒤에는 백업한 시점의 계정과 비밀번호로 로그인함.
  - **복원**: 현재 데이터를 백업 파일의 내용으로 덮어씀(합치기는 지원하지 않음). 복원 직전의 데이터는 자동으로 따로 보관함. 백업은 관리자만 할 수 있으므로 복원 화면의 계정은 관리자로 고정하고, 백업한 시점의 관리자 비밀번호로 확인함.
  - **복원 시점**: 데이터 관리 화면에서는 복원을 예약한 뒤 프로그램을 다시 시작해 수행함. 최초 실행 화면의 시작 방법 선택에서도 새로 시작하는 대신 백업에서 복원할 수 있음(PC 교체, 재설치).
  - **활동 기록**: 백업은 "백업"으로 기록함. 복원은 복원을 마친 직후 복원한 데이터에 "복원"으로 기록하며(백업 파일의 이름, 백업 일시), 기록자는 관리자 계정임. 기록에 실패해도 복원은 완료된 것으로 보고 실패했다는 것만 알림.
  - **버전**: 프로그램보다 새 버전에서 만든 백업은 복원을 거부함. 과거 버전의 백업은 복원하면서 현재 버전의 구조로 바꿈(Flyway 마이그레이션). 바꾸지 못하면 복원하지 않고 기존 데이터를 그대로 둠.
* **가져오기 공통**
  - **파일 형식**: 엑셀(xlsx, xls)과 CSV. 엑셀은 암호가 걸린 파일도 읽으며, CSV는 인코딩을 자동으로 판별하되 직접 바꿀 수 있음.
  - **진행 방식**: 다이얼로그가 아니라 탭 안에서 단계별로 진행함. (파일 선택 → 열 지정 → 매핑 → 검토 및 선택 → 백업 → 반영. 매핑은 수입/지출에만 있음)
  - **파일 선택**: 회계 연도(관계자 제외), 파일, 암호, 시트, 머리글 행을 지정함. 파일은 이때 한 번만 읽음.
  - **열 지정**: 파일의 형식을 정해 두지 않고, 프로그램의 항목마다 파일의 열을 사용자가 연결함. 머리글 이름으로 자동 추측하고 앞쪽 몇 행을 미리 보여줌.
  - **검토 및 선택**: 행마다 상태(정상/경고/오류/건너뜀)와 사유를 보여주고 가져올 행을 체크박스로 고름. 오류 행은 고를 수 없음. 표 머리글의 체크박스로 전체를 고르거나 뺄 수 있고(모든 행이 체크되었을 때만 체크로 표시), "기본 선택으로"를 누르면 처음 분석했을 때의 선택(오류와 중복 의심을 뺀 모든 행)으로 되돌림. 선택된 행의 건수와 합계를 표시함.
  - **백업**: 반영하기 전에 전체 데이터 백업을 안내하며, 백업에 성공해야 반영할 수 있음. 백업한 뒤에 활동 기록이 새로 생겼으면(데이터가 바뀌었을 수 있으므로) 백업을 다시 받아야 함.
  - **반영**: 선택된 행 전체를 한 트랜잭션으로 처리하며 추가만 함(기존 데이터를 지우거나 덮어쓰지 않음). 반영 직전에 전부 다시 검증하여 화면에 보인 것과 하나라도 다르면 전체를 취소하고 검토 단계로 돌아감.
  - **메뉴 이동**: 가져오기 도중에 다른 메뉴로 이동할 수 있으며 돌아오면 같은 단계에서 이어짐. 사용자가 입력한 것(읽어 둔 파일 내용, 열 지정, 직접 한 매핑, 직접 바꾼 선택)은 유지하고, 자동 매핑, 행의 상태, 중복 여부는 현재 데이터로 다시 계산하여 달라진 내용을 알려줌(달라진 것이 있으면 검토 단계에서 다시 확인하게 함). 직접 매핑한 대상이 삭제되었거나 쓸 수 없게 되었으면 매핑을 해제함. 회계 연도가 삭제되었으면 가져오기를 취소하고, 마감되었으면 반영을 막음.
  - **회계 연도**: 가져오기를 시작하기 전에 탭에서 고르며, 가져오는 도중에는 바꿀 수 없음(바꾸려면 취소하고 다시 시작).
  - **프로그램 종료**: 진행 중인 가져오기는 저장되지 않으므로, 가져오는 도중에 프로그램을 끝내려 하면 확인을 받음.
  - **활동 기록**: 가져오기 한 번을 "가져오기" 한 건으로 기록함. 요약(회계 연도, 파일명, 건수, 합계)과 함께, 추가 등록된 내용 전체를 건별로 기록함. 관계자는 회계 연도를 적지 않음.
* **관계자 가져오기**
  - **열**: 이름은 필수이고 비고와 상태는 지정하지 않아도 됨. 구분은 파일 전체를 한 구분(개인/내부부서/업체/단체/기타)으로 정하거나 구분 열에서 읽음. 구분 열의 값은 다섯 구분 중 하나여야 하며(띄어쓰기는 무시), 비어 있거나 다른 값이면 오류.
  - **상태**: "숨김"(또는 Y, 예, O, TRUE, 1)이면 숨긴 관계자로, 비어 있거나 "표시"(또는 N, 아니오, X, FALSE, 0)이면 보이는 관계자로 가져옴. 그 밖의 값은 오류.
  - **이름과 비고**: 이름이 빈 행(빈 줄 등)은 건너뜀. 이름이 100자를 넘으면 오류이고, 비고는 100자를 넘으면 잘라서 저장하고 경고로 알림. 검토 단계의 표에는 파일의 비고(잘린 값)를 보이며, 비고 열을 지정하지 않았으면 비고 칸을 두지 않음.
  - **중복**: 구분, 이름, 비고가 모두 같은 관계자가 이미 있으면 "중복 의심" 경고로 표시하고 기본 선택에서 뺌. 건수로 비교함(같은 관계자가 이미 1명 있고 파일에 2행 있으면 1행만 이미 있는 관계자와 겹침). 파일 안에서 같은 관계자가 다시 나오는 행도 중복 의심임.
  - **동명이인**: 중복 의심이 아니면서 이름이 같은 관계자가 이미 있거나 파일의 앞쪽 행에 있으면 "동명이인" 경고만 하고 선택은 그대로 둠.
  - **기존 관계자**: 추가만 하며 기존 관계자의 구분, 비고, 숨김 여부를 바꾸지 않음. 그룹은 가져오지 않음(수입을 저장할 때 자동으로 만들어짐).
* **예산 가져오기**
  - **계층**: 단계별 열(예: 관/항/목)을 순서대로 지정하거나, "예산A > 예산B > 예산C"처럼 전체 경로가 적힌 열 하나를 지정함. 빈 칸과 병합된 셀은 윗 행의 값을 이어받게 할 수 있음.
  - **구분**: 읽는 시트 전체가 수입 또는 지출 / 구분 열 중에서 고름. 수입과 지출이 시트로 나뉘어 있으면 시트마다 따로 가져옴. 구분 열의 값은 "수입" 또는 "지출"이어야 함.
  - **금액**: 말단 예산의 금액만 저장함(빈 칸은 0). 상위 예산에 적힌 금액이 하위 예산의 합계와 다르면 경고로 알림. 금액을 읽을 수 없거나 음수인 행은 오류.
  - **비고**: 비고 열은 지정하지 않아도 됨. 100자를 넘으면 잘라서 가져오고 경고로 알림. 빈 칸은 비고가 없는 것으로 봄. 검토 단계의 표에는 파일의 비고를 보이며, 비고 열을 지정하지 않았으면 비고 칸을 두지 않음. 기존 예산의 비고를 바꾸거나 지우는 건(파일의 비고가 빈 칸)은 설명에 기존 비고를 적음.
  - **행 없는 상위 예산**: 하위 예산의 경로에만 나오고 자기 행이 없는 상위 예산도 함께 추가함(비고 없음). 예산명이 하나도 없는 행(빈 줄 등)은 건너뜀.
  - **선택**: 계층 구조로 보여주며, 상위 예산을 빼면 하위 예산도 빠지고 하위 예산을 고르면 상위 예산도 함께 선택됨.
  - **기존 예산**: 구분과 전체 경로가 같으면 같은 예산으로 봄. 없는 예산만 추가하고 삭제는 하지 않음. 이미 있는 예산은 건너뛰되, 금액이나 비고가 파일과 다르면 파일의 값으로 갱신하도록 선택할 수 있음(비고만 달라도 갱신 대상). 금액은 파일과 기존 예산이 모두 말단 예산일 때만 견주며, 비고는 비고 열을 지정했고 그 예산의 행이 파일에 있을 때만 견줌(지정하지 않으면 기존 비고를 그대로 둠). 내역이 없는 기존 말단 예산에 하위 예산이 추가되면 그 예산의 금액이 하위 예산의 합계로 바뀐다고 경고함.
  - **오류**: 이름에 `<` 또는 `>`가 있거나 50자를 넘는 행, 상위 단계의 예산명이 비어 있는 행, 파일 안에서 구분과 전체 경로가 겹치는 행, 수입/지출 내역이 있는 예산의 하위로 들어가는 행. 상위 예산이 오류이면 그 하위 예산도 오류.
* **수입/지출 가져오기**
  - **구분**: 파일 전체가 수입 또는 지출 / 구분 열 / 수입 금액 열과 지출 금액 열이 따로 있는 형태 중에서 고름. 구분 열의 값은 "수입"/"입금"이면 수입, "지출"/"출금"이면 지출로 읽고, 그 밖의 값(다른 프로그램의 "세입"/"세출" 등)은 매핑 단계에서 수입 또는 지출로 직접 지정함. 지정하지 않은 값을 쓰는 행은 오류. 금액 열이 따로 있을 때는 금액이 적힌 쪽으로 구분을 정하며(0은 빈 칸으로 봄), 양쪽에 모두 적힌 행은 오류.
  - **날짜와 금액**: 엑셀의 날짜 셀과 `2026-03-05`, `2026.3.5`, `2026년 3월 5일`, `20260305`, `26.3.5` 형식의 글자를 읽으며 연/월/일이 다른 열이어도 됨. `3/5`, `3월 5일`처럼 연도가 없으면 회계 연도의 기간으로 연도를 정함. 금액은 `1,000,000원` 같은 표기를 읽음. 날짜와 금액이 모두 없는 행(합계, 빈 줄 등)은 건너뜀.
  - **내용과 비고**: 100자를 넘으면 잘라서 저장하고 경고로 알림. 지출 행의 내용이 비어 있으면 그 행 예산의 최하위 예산명으로 채우고 경고로 알림(중복 의심도 채운 값으로 비교함). 비고 열은 지정하지 않아도 됨. 검토 단계의 표에는 내용 다음에 파일의 비고(잘린 값)를 보이며, 비고 열을 지정하지 않았으면 비고 칸을 두지 않음.
  - **기간**: 날짜가 선택한 회계 연도의 기간을 벗어난 행은 오류이며, 사유에 회계 연도의 기간을 함께 적음.
  - **봉헌자/수취인**: 한 칸에 여러 명을 쉼표(`,`)로 구분해 적을 수 있으며(CSV에서는 `"홍길동,김철수"`처럼 큰따옴표로 묶인 칸) 각 성명의 앞뒤 공백은 제거함. 한 칸에 적힌 성명들은 매핑 목록에서 한 줄("홍길동, 김철수")이며, 공백과 중복을 정리한 값이 같으면 같은 줄임. 성명의 순서는 내역에 저장되는 순서이므로 순서만 다른 값은 다른 줄임. 지출에 2명 이상이 적힌 행은 오류.
  - **자동 매핑(예산)**: 구분별로, 전체 경로가 있으면 경로가 같은 말단 예산에, 이름만 있으면 그 이름의 말단 예산이 하나일 때 연결함. 예산을 자동으로 추가하지 않음. 직접 한 매핑이 자동 매핑보다 우선하되, 매핑한 예산이 삭제되었거나 말단 예산이 아니게 되었으면 따르지 않음.
  - **자동 매핑(봉헌자/수취인)**: 칸에 적힌 성명마다 성명이 같은 대상을 찾아, 모두 찾았을 때만 찾은 대상들에 연결함. 동명이인이 있으면 숨김 처리되지 않은 대상 중 가장 최근에 등록된 대상을 고르고, 모두 숨김이면 찾지 못한 것으로 봄. 일부만 찾았으면 실패로 처리하되, 직접 매핑할 때 찾은 대상을 미리 넣어 두고 찾지 못한 성명으로 자동완성을 띄움. 대상을 자동으로 추가하지 않음.
  - **일괄 매핑**: 자동 매핑에 실패한 구분, 예산, 성명을 각각 목록으로 보여주며(같은 값은 한 줄. 예산과 성명은 구분까지 같아야 한 줄이므로, 같은 성명이 수입과 지출에 모두 있으면 두 줄로 나와 각각 매핑함), 목록은 "(빈 칸)"을 맨 위에 두고 파일의 값 순서(값이 같으면 수입 먼저)로 정렬함. 목록에서 매핑하면 그 값을 쓰는 모든 행에 적용됨. 구분이 정해져야 그 행의 예산과 봉헌자/수취인을 연결할 수 있으므로, 구분을 매핑하면 예산과 성명의 목록이 늘 수 있음. 여러 줄을 골라 한 번에 매핑할 수 있음. 봉헌자/수취인이 비어 있는 행은 수입과 지출 각각 "(빈 칸)" 한 줄로 나오며 "무명" 같은 대상에 매핑함. 매핑되지 않은 값을 쓰는 행은 오류.
  - **예산 선택**: 예산 선택 다이얼로그에서 해당 구분의 말단 예산을 고르며, 그 자리에서 예산을 추가/수정/삭제/순서 변경할 수 있음(수정은 수정 버튼으로 하며, 예산을 더블클릭하면 그 예산에 매핑함). 이 변경은 가져오기와 무관하게 즉시 저장됨.
  - **봉헌자/수취인 선택**: 수입/지출 입력의 자동완성란으로 고르며, 자동완성의 "신규 추가"로 그 자리에서 등록할 수 있음. 입력할 때와 같이 수입의 줄은 여러 명에 매핑할 수 있고 그룹 기능을 쓰며, 고른 순서대로 내역에 저장됨("홍길동, 김철수"나 "홍길동 가정"을 가족 구성원에 매핑하는 경우 등). 지출의 줄은 그룹 기능 없이 한 명에 매핑하며, 수입과 지출의 성명을 함께 골라 매핑할 때도 한 명만 고를 수 있음. 여러 명에 매핑한 대상 중 한 명이라도 삭제되면 그 매핑은 따르지 않음.
  - **다시 매핑**: 예산이나 봉헌자/수취인을 새로 등록하면(선택 다이얼로그에서든 다른 메뉴에서든) 이름이 같은 값은 자동으로 매핑됨.
  - **중복**: 일자, 구분, 예산, 금액, 내용, 봉헌자/수취인이 모두 같은 내역이 이미 있으면 "중복 의심" 경고로 표시하고 기본 선택에서 뺌. 건수로 비교함(같은 내역이 이미 2건 있고 파일에 3건 있으면 1건만 새 내역으로 봄).
  - **그룹**: 봉헌자가 2명 이상인 수입은 직접 입력할 때와 같이 그룹을 자동 생성함.
* **내보내기**
  - 등록된 관계자 전체, 또는 선택한 회계 연도의 예산이나 수입/지출 내역 전체를 엑셀(xlsx) 또는 CSV로 저장함. 엑셀은 암호를 설정할 수 있음.
  - 관계자: 구분, 이름, 비고, 상태("숨김"/"표시"). 숨긴 관계자를 포함해 관계자 하나가 한 행이며, 구분(개인, 내부부서, 업체, 단체, 기타 순), 이름순으로 적음. 그룹은 내보내지 않음.
  - 예산: 구분, 단계별 예산명, 예산액, 수입액/집행액, 비고. 상위 예산을 포함해 예산 하나가 한 행.
  - 수입/지출: 구분, 일자, 단계별 예산명, 금액, 내용, 봉헌자/수취인, 비고. 봉헌자/수취인은 내역에 기록된 당시의 이름을 쉼표로 이어 적음.
  - 단계별 예산명은 "예산 1단계", "예산 2단계"처럼 칸을 나눠 적으며, 칸의 수는 가장 깊은 예산에 맞춤.
  - 엑셀에서는 일자를 날짜 셀로, 금액을 숫자 셀로 적음. CSV는 UTF-8(BOM 포함)이며 일자는 `2026-03-05` 형식, 금액은 자릿수 구분 없이 적음. CSV에서 `=`, `+`, `-`, `@`로 시작하는 글자 값은 엑셀이 수식으로 실행하지 않도록 앞에 작은따옴표(`'`)를 붙이며, 가져오기는 이 작은따옴표를 떼고 읽음.
  - 내보낸 파일은 그대로 다시 가져올 수 있으며, 같은 머리글의 빈 양식(예산 3단계)을 내려받을 수 있음. 양식은 가져올 데이터를 정리할 때 쓰므로 "가져오기" 버튼 옆에 둠.
  - 내보내기는 활동 기록에 "내보내기"로 기록함(대상, 회계 연도, 파일 이름, 건수. 관계자는 회계 연도를 적지 않음). 빈 양식 내려받기는 기록하지 않음.

## 6. 비기능 요구사항 (Non-Functional Requirements)
* **보안성**: 사용자별 비밀번호 기반 DB 접근 제어 및 설정 파일 보안 유지.
* **성능**: 100ms 이내의 빠른 자동완성 응답, 대량 데이터 처리 시 비동기(SwingWorker) 처리를 통한 UI 프리징 방지.
* **신뢰성**: 모든 작업의 트랜잭션 원자성 보장 및 데이터 무결성 검증.
* **사용성**: 명확한 에러 피드백 제공 및 입력 제약 조건(100자 제한 등)을 통한 사용자 실수 방지. 글자 수가 정해진 입력란은 최대 길이를 넘겨 입력할 수 없으며, 붙여넣은 글자가 넘치면 넘친 부분을 잘라내고 입력란 아래에 잠깐 안내함.
